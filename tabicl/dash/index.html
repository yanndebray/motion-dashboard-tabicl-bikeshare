Three tasks. Bikes to carry uphill is regression on 372 training weekdays (Jan 2011 to Jun 2012): calendar, the 6–9 am weather from the UCI hourly data, yesterday's value and the last five weekdays' average. Empty by 9 am is classification per hill station and weekday, using the same estimate as the overview dashboard (a dock that starts full and runs out). Hourly rides uses TabICL's time-series forecaster on two series.

What the hosted API needs. /v1/infer timed out (HTTP 524 after about 100 s) with 4,464 context rows, so the API run keeps the 2,000 most recent and sends the test set in six chunks. /v1/forecast refused 56 days of hourly history (HTTP 503) and accepts 28. The local run with the full 4,464 rows scored AUC 0.940; with the same 2,000 rows it matches the API.

One change that mattered. Predicting the raw count, TabICL ran 20 bikes low because summer 2012 set new highs and it leaned on 2011 days. Predicting the change from the recent level cut its error from 34 to 22 bikes.
